# Connect over MCP

The platform also runs an MCP server at `https://app.dozaldevs.com/mcp`. A human whose agent already speaks MCP (Hermes, Claude Code, Cursor) can connect it with the same `dze_` key and skip the CLI. If you have `dozaldevs`, you don't need this.

## Connect

The key goes in `DOZALDEVS_API_KEY`, as a bearer header. A person mints it. You don't.

Hermes, in `config.yaml`:

```yaml
mcp_servers:
  dozaldevs:
    url: https://app.dozaldevs.com/mcp
    headers:
      Authorization: "Bearer ${DOZALDEVS_API_KEY}"
```

Claude Code:

```sh
claude mcp add --transport http dozaldevs https://app.dozaldevs.com/mcp \
  --header "Authorization: Bearer $DOZALDEVS_API_KEY"
```

Cursor and other clients: the same URL and the same `Authorization` header. Claude.ai and ChatGPT can't connect yet, because they need OAuth and that isn't live. Only the key works today. Person sessions are refused.

## The tools

- `list_dozals`, `run_dozal`, `list_tasks`, `get_task`, `list_waits`, `decide_wait_action`, `submit_wait_decisions`, `decide_task`.
- `api_search` finds an operation by words, `api_describe` shows its inputs and error codes, `api_read` calls any read, `api_write` calls any other one. Search, then describe, then call.
- A Viewer key sees no write tools.
- The organization is never an argument.
- `get_task` takes `wait_seconds` (up to 50) to wait while the run is working; it returns once the run finishes or is waiting on a person, or at the deadline. Use it once per question, never in a loop.
- Results are short by default. Ask for `response_format: "detailed"` only when you need the full body. A result over 60,000 characters is cut, and its last line says which `limit` and `cursor` to use.

## MCP or the CLI

- Prefer the CLI when you have a shell and `dozaldevs` is installed. Its commands and skills cover the whole API, and the job skills tell you what to do.
- Prefer MCP when the agent has no shell (a hosted or sandboxed client) or the human already runs an MCP client and wants it connected.
- Everything else is the same: the key's level, errors with `next_step`, the async model, and the person-only steps in the main skill.
